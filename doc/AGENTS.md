# AI 开发指令 - A股热门题材/牛散持仓聚合网站

## 1. 项目概述
开发 A 股热门题材、热门股票、牛散持仓一站式聚合网站。
- 前端：React + TypeScript + Vite
- 后端：Node.js + Express
- 数据：东方财富、同花顺、特特网公开数据
- 核心：股票直接关联牛散，点击进入站内牛散详情页
- 用途：个人学习研究，非商用、非投资建议
- 部署：公网 HTTPS 可访问

## 2. 强制技术规范
- 必须使用 TypeScript，前后端类型与 TECH_DESIGN 一致
- 必须使用函数式组件 + Hooks
- 样式：CSS / CSS Modules，简洁清爽
- 必须复用组件：HotCard、Layout、TabSwitch、BullDetail
- 组件名 PascalCase，函数/变量 camelCase
- 前端**禁止**直接请求源站，全部走后端中转

## 3. 后端强制要求
- 接口严格按以下路径实现：
  - GET /api/hot/:source/:type
  - GET /api/bull/:name
  - GET /api/hot/all（可选）
- 统一返回格式，异常缓存兜底
- 缓存 TTL：5～10 分钟，按平台+类型独立缓存
- 请求带上合理 User-Agent、Referer
- 控制请求频率，保护源站
- 仅抓取公开数据，不爬付费接口

## 4. 前端页面要求
### 首页
- 3 平台卡片网格：东方财富、同花顺、特特网
- 支持切换：热门题材 / 热门股票 / 牛散持仓
- 股票条目右侧显示可点击牛散姓名，无则不显示
- 单条展示：排名 | 名称(代码) | 涨幅 | 牛散（如有）
- 桌面 3 列，移动端 1 列
- 排名 1～3 视觉强调

### 牛散详情页
- 牛散姓名、简介、投资风格
- 最新持仓列表：代码、名称、占比、变动趋势
- 数据更新时间
- 每条持仓可跳转原平台

### 异常展示
- 单个平台加载失败：仅该卡片提示，不影响整页
- 加载中、无数据、错误均提供友好文案

## 5. 缓存与性能
- 缓存 TTL 默认 600 秒，支持环境变量 CACHE_TTL
- 10 分钟内刷新不重复请求上游
- 接口失败用缓存兜底，禁止 Mock 数据
- 页面显示“更新于 X 分钟前”

## 6. 合规与声明（必须）
页脚固定展示：
- 本项目仅供个人学习研究
- 非商用
- 非投资建议
- 数据来源：东方财富、同花顺、特特网（公开数据）

## 7. 测试验收标准
- 每个平台验证 ≥10 条数据正确
- 单平台挂掉，其他平台正常展示
- 牛散点击可正常进入详情页
- 无牛散的股票不显示标签
- 移动端适配正常
- 10 分钟内刷新不频繁请求上游
