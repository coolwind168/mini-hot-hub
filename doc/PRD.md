# A股热门题材/热门股票/牛散持仓聚合网站 - PRD

## 一、产品概述
本项目为 A 股热门题材、热门股票、牛散持仓一站式聚合网站，首页以卡片网格展示东方财富、同花顺、特特网三大平台公开真实数据，访客打开链接即可浏览，无需登录。
核心特色：热门股票右侧直接标识关联牛散，点击进入**站内牛散详情页**，查看该牛散最新全部持仓股票。
全站仅用于个人学习研究，非商用、非投资建议，支持公网 HTTPS 访问。

## 二、目标用户
1. 希望快速浏览全市场热点题材、热门股票、牛散持仓动向的股民、学生、个人研究者
2. 对全栈开发、后端中转、数据聚合、缓存设计感兴趣的技术学习者

## 三、核心功能（MVP 必须实现）

### 3.1 首页卡片网格
- 平台卡片：东方财富、同花顺、特特网，共 3 张卡片
- 榜单类型：热门题材 / 热门股票 / 牛散持仓，支持切换
- 单条数据必展示：
  - 排名 rank
  - 名称/标题 title
  - 代码 code
  - 涨幅/热度 change/heat
  - 跳转原平台链接 url
- 热门股票条目**右侧直接显示关联牛散姓名（可点击）**
- 股票无关联牛散时，**不显示任何标签**

### 3.2 牛散关联核心功能
- 牛散数据**全部来源：特特网**
- 热门股票展示格式：排名 | 名称(代码) 涨幅 | 牛散：XXX
- 点击牛散姓名 → 打开**站内牛散详情页**
- 牛散详情页内容：
  - 牛散姓名
  - 简介/投资风格
  - 最新爬取的全部持仓股票列表
  - 持仓股票代码、名称、占比、变动趋势
  - 每只持仓支持跳转原平台
  - 数据更新时间

### 3.3 后端接口（必须后端中转，前端不直连）
1. 获取单平台榜单
   - 请求：GET /api/hot/:source/:type
   - source：eastmoney / 10jqka / tetewang
   - type：theme / stock / bull
2. 获取牛散详情与持仓
   - 请求：GET /api/bull/:name
   - 数据源：特特网
3. 批量获取全平台（可选）
   - 请求：GET /api/hot/all
4. 统一返回格式，异常缓存兜底

### 3.4 缓存策略
- 按 **平台 + 榜单类型** 独立缓存
- 缓存 TTL：5～10 分钟
- 页面展示：更新于 X 分钟前
- 接口失败、限流、异常时：使用缓存兜底，不展示 Mock 数据

### 3.5 异常处理
- 单个平台/榜单加载失败，不影响其他卡片正常展示
- 无牛散关联时不显示标签
- 加载失败展示友好提示
- 控制请求频率，避免对源站造成影响

### 3.6 部署要求
- GitHub 托管代码
- 公网 HTTPS 可访问
- 响应式布局：桌面多列、手机单列
- 加载速度快、移动端友好

## 四、界面设计要求
- 风格简洁、信息清晰、卡片分区明确
- 热门股票行：排名 | 名称(代码) 涨幅 | 牛散：姓名（高亮可点击）
- 牛散详情页：字段清晰、列表整洁、跳转正常
- 页脚固定声明：
  - 本项目仅供个人学习研究
  - 非商用
  - 非投资建议
  - 数据来源：东方财富、同花顺、特特网（公开数据）

## 五、技术栈
- 前端：React + TypeScript + Vite + CSS
- 后端：Node.js + Express
- 部署：Vercel + Railway（可自选）
- 约束：后端中转、请求频率控制、缓存、异常兜底、日志可查

## 六、合规与风险约束
- 仅爬取公开可访问数据，不破解、不爬付费接口
- 不存储用户隐私、不存储敏感数据
- 严格控制请求频率，保护源站服务
- 页脚必须标注：非投资建议，仅供学习使用
